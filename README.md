# WatchfulEye

News and geopolitical intelligence for iPhone and Android: how a story is framed, why it matters, and what may follow. Published by Monarc Systems, Inc.

## What it does

- **Context:** short briefs on what happened, the sources, and what it affects, with inference labeled.
- **Perspective:** how different outlets frame the same story, side by side.
- **What's next:** upcoming decisions, deadlines and signals, plus "Ask the Eye" for questions about a story.

## About this page

This is a profile page. WatchfulEye's app and servers are closed source, and this repository contains no source code.

WatchfulEye is not the Freeform series *The Watchful Eye*, and it is not a camera or security app.
